# Creatividad asistida por IA — imágenes y videos

## Objetivo
Crear material visual útil para la web y las redes de Igmaustral sin perder fidelidad al producto real.

## Qué podemos producir
- Recortes de producto para fichas de la web.
- Fondos y composiciones comerciales para campañas.
- Ideas visuales y guiones para videos verticales.
- Storyboards, textos en pantalla, subtítulos y llamadas a la acción.
- Variantes creativas para anuncios y publicaciones.

## Flujo recomendado
1. Seleccionar el producto y definir el objetivo de la pieza.
2. Usar una foto real, nítida y bien iluminada como referencia cuando sea necesario mantener la apariencia exacta.
3. Definir formato: cuadrado para catálogo, vertical 9:16 para Reels/TikTok o apaisado para banners.
4. Crear la imagen, guion o video con herramientas disponibles.
5. Revisar que el material no altere medidas, textura, color, cantidad, material ni presentación del producto.
6. Añadir marca, texto y precio solo después de verificar ortografía y condiciones comerciales.
7. Obtener aprobación antes de publicar y guardar la versión final junto con el texto de la campaña.

## Límites importantes
- Una imagen generada puede representar de forma incorrecta la textura o composición real. No usarla como prueba técnica del producto.
- No mostrar absorción, resistencia, certificaciones o resultados que no hayan sido comprobados.
- Si una escena es ilustrativa o generada, no presentarla como una demostración real.
- Mantener fotos reales para fichas técnicas y detalles que el comprador necesita verificar.
- No incluir rostros, logotipos de terceros ni datos de clientes sin permiso.

## Integración futura
Más adelante se puede evaluar un flujo que reciba el nombre del producto, el formato y el objetivo, genere un brief o guion, cree recursos con servicios compatibles y guarde los resultados en una biblioteca aprobada.

Antes de automatizar generación de imágenes o videos hay que elegir las herramientas, revisar precios, licencias comerciales, acceso por API, almacenamiento y requisitos técnicos. No se guardan claves API en GitHub.
